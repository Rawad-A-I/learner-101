# Basic Hardware Components
**Problem:** A computer system needs distinct hardware roles to control execution, hold data/programs, and exchange data with the outside world.
**Mechanism:** Four basic elements: the processor (controls the computer, performs data processing, aka the CPU), main memory (stores data and programs, volatile, aka real/primary memory), I/O modules (move data between the computer and its external environment, e.g. secondary memory, communications equipment, terminals), and the system bus (connects them, covered separately).

## Key points
- [ ] The processor controls the operation of the computer and performs its data processing functions; it is referred to as the CPU. (p.4)
- [ ] Main memory stores data and programs, is typically volatile (contents lost on shutdown), and is referred to as real or primary memory. (p.5)
- [x] I/O modules move data between the computer and its external environment, including secondary memory devices (e.g. disks), communications equipment, and terminals. (p.6)
- [x] These four elements (processor, main memory, I/O modules, system bus) are the basic elements of a computer system. (p.3)
