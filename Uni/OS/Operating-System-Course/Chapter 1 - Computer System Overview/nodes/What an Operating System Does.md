# What an Operating System Does
**Problem:** Raw hardware is hard for users and programs to use directly.
**Mechanism:** The OS exploits (manages and allocates) the hardware resources of one or more processors, provides a set of services to system users, and manages secondary memory and I/O devices on their behalf.

## Key points
- [/] The OS exploits the hardware resources of one or more processors. (p.2)
- [ ] The OS provides a set of services to system users. (p.2)
- [/] The OS manages secondary memory and I/O devices. (p.2)
