# Microprocessors and GPUs
**Problem:** General-purpose single-chip processing needed to scale, and some workloads (graphics, arrays of data) need a different execution model than a traditional CPU.
**Mechanism:** The microprocessor put a processor on a single chip, enabling desktop/handheld computing and becoming the fastest general-purpose processors; multiprocessor chips (sockets) pack multiple cores. GPUs use SIMD (Single-Instruction Multiple Data) techniques, pioneered in supercomputers, to compute efficiently over arrays of data — no longer just for rendering graphics, but also general numerical work like physics simulations and spreadsheet computation.

## Key points
- [ ] The microprocessor is the invention that brought about desktop and handheld computing by putting a processor on a single chip. (p.9)
- [ ] Multiprocessor chips (sockets) contain multiple processors (cores) on the same chip. (p.9)
- [ ] GPUs provide efficient computation on arrays of data using SIMD techniques pioneered in supercomputers. (p.10)
- [ ] GPUs are no longer used just for rendering graphics; they're also used for general numerical processing such as physics simulations for games and computations on large spreadsheets. (p.10)
